# 河北大学《操作系统实验》课程大纲与实验项目总览

本文件归纳了河北大学电子信息工程学院《操作系统实验》课程（选修课，配套实验指导书）全部 7 个实验项目的核心要点、知识图谱与作答精要，供后续实验复刻使用。

---

## 实验项目总目录与关键要点

### 实验一：进程描述和进程控制
- **核心知识点**：进程与进程控制块（PCB）、进程状态转换、Windows 任务管理器、系统进程与用户进程区别、Windows 核心进程（`smss.exe`, `csrss.exe`, `winlogon.exe`, `explorer.exe`）。
- **编程与 API**：`GetCurrentProcessId()`, `GetProcessVersion()`, `CreateToolhelp32Snapshot()`, `Process32First()`, `Process32Next()`, `CreateProcess()`。
- **典型考查问题**：
  - 结束 `explorer.exe` 的现象：桌面任务栏、桌面图标瞬间消失，仅剩壁纸和运行窗口；在任务管理器“新建任务”输入 `explorer.exe` 可恢复。结论：`explorer.exe` 是 Windows 图形外壳（GUI Shell）进程。
  - `csrss.exe` 的作用：客户端/服务器运行时子系统，负责控制台窗口管理与进程创建/终止协助，属于保护进程无法强行终止。
  - `winlogon.exe` 的作用：处理用户登录、注销、安全注意序列（Ctrl+Alt+Del）等。

---

### 实验二：进程同步和互斥
- **核心知识点**：临界资源、临界区、互斥访问、同步机制、经典生产者-消费者问题、读者-写者问题。
- **编程与 API**：
  - 互斥量（Mutex）：`CreateMutex()`, `WaitForSingleObject()`, `ReleaseMutex()`。
  - 信号量（Semaphore）：`CreateSemaphore()`, `ReleaseSemaphore()`。
  - 事件（Event）：`CreateEvent()`, `SetEvent()`, `ResetEvent()`。
- **实验报告作答精要**：
  - 重点观察互斥量/信号量加锁前后控制台输出时序是否乱序。
  - 遇到死锁的成因分析与避免策略。

---

### 实验三：进程调度
- **核心知识点**：进程调度算法模拟（先来先服务 FCFS、短作业优先 SJF、高响应比优先 HRRN、时间片轮转 RR、多级反馈队列）。
- **指标计算**：周转时间 = 完成时间 - 到达时间；带权周转时间 = 周转时间 / 服务时间；平均周转时间与平均带权周转时间。
- **作答重点**：
  - 各种算法在甘特图上的执行顺序对比。
  - 短作业优先可能引起的“饥饿”现象及时间片长短对系统开销的影响。

---

### 实验四：银行家算法
- **核心知识点**：死锁避免、安全状态、资源分配矩阵（`Available`, `Max`, `Allocation`, `Need`）。
- **算法流程**：安全性检查算法（Work 向量与 Finish 向量），寻找安全序列。
- **实验记录重点**：
  - 记录输入特定资源请求（`Request`）后系统试探性分配过程。
  - 给出找到的安全序列（如 `P1 -> P3 -> P4 -> P0 -> P2`），证明当前处于安全状态。

---

### 实验五：内存管理
- **核心知识点**：连续分配动态分区（首次适应算法 First Fit、最佳适应算法 Best Fit、最差适应算法 Worst Fit）、内存碎片。
- **API 体验**：Windows 虚拟内存管理 API（`VirtualAlloc`, `VirtualFree`, `VirtualQuery`, `GlobalMemoryStatusEx`）。
- **作答要点**：
  - 比较各种分区分配算法的分配速度与碎片率。
  - 物理内存与虚拟内存地址映射与换页机制。

---

### 实验六：页面置换算法的模拟实现
- **核心知识点**：虚拟存储器、缺页中断、页面淘汰策略。
- **算法对比**：最佳置换算法（OPT）、先进先出算法（FIFO）、最近最久未使用算法（LRU）、时钟置换算法（CLOCK）。
- **作答要点**：
  - 给出给定访问序列下的缺页次数与缺页率计算。
  - Belady 异常现象解释（分配物理块数增加，缺页次数反而增加）。

---

### 实验七：磁盘调度算法
- **核心知识点**：磁盘访问时间（寻道时间、旋转延迟、传输时间）。
- **调度算法**：先来先服务（FCFS）、最短寻道时间优先（SSTF）、扫描算法（SCAN / 电梯算法）、循环扫描算法（CSCAN）。
- **计算要点**：各算法的平均寻道长度与磁头移动柱面顺序。

## 💡 后续复用快速指引

每当进入新的实验（如实验二、实验三）：
1. 确认实验编号与标题（如 `实验二 进程同步和互斥`）。
2. 将该实验要求填写到模板主表格行 0、1、2、3。
3. 实验内容与步骤按上述实验知识点编写，并配以运行截图。
4. 反思部分结合具体算法或 API 编写 3 点真实体会。
