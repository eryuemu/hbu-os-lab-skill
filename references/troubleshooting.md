# WPS 与 Word 常见排版故障排查手册

本手册收录了在编辑和查看河北大学操作系统实验报告 DOCX 文件时最常见的问题与解决方案。

## 1. 封面后多出第 2 页空白页怎么办？

### 现象描述
在 WPS 中打开生成的文档，第 1 页是实验报告封面，第 2 页却是一整页空白，正文大表格被挤到了第 3 页。

### 产生原因
原模板封面最下方的“教师签字”后自带 2 个空行和 1 个分页符。当封面填充了学生真实信息后，页面高度微增，导致空行与分页符被推到了第 2 页，分页符在第 2 页再次强制分页，造成第 2 页全空。

### 解决办法（三选一）

- **方法一（最快）**：
  把光标点击在**第 2 页（空白页）的最左上角**，按键盘上的 **`Backspace` 键（退格键 `⌫`）** 连按 1~2 下，空白页随即被消除，正文自动贴上来。
- **方法二（从第 1 页删除）**：
  光标点击在**第 1 页底部“教师签字：”下划线末尾**，按键盘上的 **`Delete` 键（Del 键）** 连按 2~3 下，删除后续的空换行符与分页符。
- **方法三（显形删除）**：
  在 WPS 顶部菜单【开始】中，点亮段落工具栏中的 **`¶`（显示/隐藏编辑标记）** 按钮。此时空白页上会显现出灰色的回车箭头 `¶` 以及虚线 `······ 分页符 ······`，用鼠标直接圈选该虚线，按 `Delete` 删除即可。

## 2. 为什么正文里会有蓝色或褐色字？如何彻底消除？

### 现象描述
有些实验报告由 AI 或第三方脚本生成后，标题、代码框、括号或者填空区域呈现出明显的深蓝色（如 `#0D47A1`）或深棕色，缺乏正式报告的严肃感。

### 根源分析
OpenXML 中的 `<w:rPr>` 标签内被硬编码加入了字体颜色属性，例如：
```xml
<w:rPr>
  <w:color w:val="0D47A1"/>
</w:rPr>
```
WPS 在渲染时会严格依照该十六进制颜色码绘制文字。

### 根治方案
在生成脚本中，**坚决不插入任何 `<w:color>` 标签**。如果是已经生成的 docx，可通过 Python 解压后使用正则表达式全局清除：
```python
import zipfile, re

def remove_colors(docx_path):
    with zipfile.ZipFile(docx_path, 'r') as zin:
        xml_data = zin.read('word/document.xml').decode('utf-8')
    
    # 彻底去除所有 color 标签
    cleaned_xml = re.sub(r'<w:color[^>]*/>', '', xml_data)
```

## 3. 表格跨页断裂或边框丢失

### 现象描述
当实验内容较长时，主表格或子表格跨越到下一页，有时会发生上下边框断裂或行高异常。

### 规范配置
在 XML 生成中，为所有跨页表格添加以下核心属性：
1. **防止单行被硬生生切断**：在每个 `<w:trPr>` 中加入 `<w:cantSplit/>`，保证每个进程行或步骤不会半行在一页、半行在另一页。
2. **表头跨页重复**：如果子表格很长，在第一行的 `<w:trPr>` 中加入 `<w:tblHeader/>`，在下一页顶端自动重复显示列头（映像名称、CPU、内存等）。
3. **边框统一定义**：在 `<w:tblPr>` 内完整定义 `<w:tblBorders>`，切勿依赖软件默认边框。

## 4. 手机翻拍照片带水印和黑边

### 规范操作
很多学生习惯用手机直接拍摄电脑屏幕，往往带有手机厂商的水印（如 realme 水印、水印时间）以及屏幕下方的桌面背景。
- **必须在插入前自动化裁切**：使用本 Skill 自带的 `crop_photos.py`，默认切除底部 6% 和四周 3% 的边缘。
- **限制最大宽度**：单图宽度不超过 1920 像素，插入 Word 时的显示宽度设定为 8.0cm ~ 8.5cm，兼顾清晰度与整洁度。
